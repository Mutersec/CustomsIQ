CustomsIQ

EU trade compliance toolkit — search, classification, screening & duty API reference →

HS / CN Code Search

Describe the goods in plain language. Results are ranked by similarity against the EU Combined Nomenclature sample data.

Sanctions Screening

Screen a person or organisation against the denied-party list. Matching tolerates word order and partial names.

Code Classification

Describe the goods and get ranked code suggestions with a confidence score. Unlike the search above, this weighs how rare each word is across the nomenclature, and shows which of your terms drove each suggestion.

Customs Duty Calculation

Work out the duty owed on a consignment. A preferential rate is applied automatically when the origin qualifies for one; otherwise the standard MFN rate applies.

Review History

Sign-offs recorded against classification, screening and duty results — append-only, most recent first.

Demo project. The tariff codes, duty rates, trade agreements and sanctions list are all fictional mock data in EU Combined Nomenclature / EU Consolidated Financial Sanctions List style. No entity or agreement listed here is real, and this tool must never be used for actual customs classification, duty calculation or sanctions screening. Production use requires the official EU TARIC database and the official EU Consolidated Financial Sanctions List.
